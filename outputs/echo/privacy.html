Privacy page

Your letter should not become someone else's data.

Echo is a local-first prototype for preserving a human, a place, and a time. The private letter, title, media, mood, goals, and sealed details stay in this browser unless you export them yourself.

What Echo stores

Letters, returned and sealed Echoes, draft text, media attachments, mood, goals, theme preference, Archive Key state, and optional moment context are stored locally in browser storage.

What Echo does not send

Echo does not send letter text, titles, media, moods, goals, or emotional details to the context API. The API boundary accepts only date and coordinates for place, weather, and daylight enrichment.

AI boundary

Echo has no chatbot or assistant surface. The small writing polish control works only on highlighted text and is covered by the Promptfoo policy gate before any AI provider is allowed.

Backups

Exports are local JSON files that may include sealed content. Import and export are user actions, and the app warns before creating a backup that contains locked letters.

Prototype limits

This version does not include accounts, cloud sync, server-side storage, or remote transcription. Future sync should preserve the same sealed-content rule and keep secrets on a server route, not in the browser.
